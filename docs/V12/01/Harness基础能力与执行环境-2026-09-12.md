# Harness 基础能力与执行环境

日期：2026-09-12。范围：基础聊天、命令、网络检索与执行记录；不改变 HR 私有业务协议。

## 结论

聊天客户端和执行环境分离。Web、Desktop 是观察与控制入口；任务绑定工作区和执行设备，换客户端不自动换执行位置。

| 场景 | 建议执行环境 | 文件范围 |
| --- | --- | --- |
| 企业 Web 托管任务 | 服务端隔离运行时，复用现有 container 实现 | 任务工作区与授权挂载 |
| 桌面本地项目任务 | 用户设备上的本地运行时 | 用户选定的项目目录；执行权限由本地边界约束 |
| Web 查看已有桌面任务 | 仍在原桌面设备执行 | 原绑定目录，设备离线不得降级到服务器 |
| 单用户开发部署 | 显式 host 模式 | 专用开发工作区，不能当成企业多租户隔离 |

“运行在宿主机”描述执行位置，不能证明隔离。仅设置 cwd、过滤环境变量、创建 Git worktree 都不是文件系统或网络沙箱。

## 官方资料及适用范围

- [Codex Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environment)：云任务创建容器，任务循环在容器内运行，网络访问有独立策略。适合作为服务端任务环境参考。
- [Codex Windows sandbox](https://openai.com/index/building-codex-windows-sandbox/)：本地工具通过操作系统权限边界约束命令及子进程；本地运行与隔离并不冲突。
- [Claude Code Remote Control](https://code.claude.com/docs/en/remote-control)：浏览器可以控制仍在用户机器运行的会话。支持客户端与执行位置分离这一设计。
- [Claude Code sandboxing](https://code.claude.com/docs/en/sandboxing)：文件系统与网络边界由 OS 机制执行，边界内操作减少逐条确认。
- [Anthropic containment architecture](https://www.anthropic.com/engineering/how-we-contain-claude)：面向办公用户的本地执行采用更强隔离；对话循环与代码执行分开，执行环境故障不应让对话不可用。
- [OpenHands Docker Sandbox](https://docs.openhands.dev/openhands/usage/sandboxes/docker)：推荐 Docker 沙箱，授权目录通过挂载进入工作区。

上述是产品与项目的公开实现事实；本项目建议基于其共同原则，不代表 SnowHarness 已具备相同隔离能力。

## 已实现

- 登记三个正式内置工具：`shell`、`web-search`、`web-fetch`。复用已有 ToolProvider、Tool、已发布 Schema Revision、权限决策及 Worker。新管理员引导会登记；已有部署可运行下面的登记命令。重复执行不覆盖已发布版本或停用决定。
- 生产能力目录可纳入无 Connection 的 builtin；`knowledge.search` 仍专用于内部知识库。Agent 是可选资产，不是聊天或基础工具的前提。
- 命令目标随 Invocation 的 CapabilityCatalog 摘要冻结：host/container 的工作目录、配额、网络策略，或桌面的设备、用户、WorkspaceBinding 及版本。工具参数不能指定执行设备。重试验证原快照；桌面离线、撤销、跨租户或绑定改变都不能回落宿主机。
- Web 默认生产 container；开发 host 必须显式配置。内置 shell 直接选用冻结 Runtime，不使用容器失败后 host 降级路径。Host 的 cwd 和环境白名单不构成多租户隔离。
- Desktop Worker 通过现有控制面 URL 与 Gateway Token 发起请求，网关只接受 ToolCall/Attempt ID，从持久数据恢复命令，经已有设备认证、签名 RPC 和租约执行。发送前持久 CAS 阻止同一 Attempt 重复执行；连接中断后的未知副作用不自动重放。
- macOS Desktop 使用 SQLite 中用户选定的工作区、实际路径校验与 `sandbox-exec`。读写受目录边界约束，复用本机子进程实现。当前实现不支持 Windows/Linux 本地沙箱，不能宣称跨平台完成。
- Web 网络工具沿用已有域名允许列表、拒绝规则、SSRF 校验、超时及结果大小合同。空允许列表默认拒绝；不会为了回答问题静默开放全部网络。搜索复用现有 DuckDuckGo 适配器，搜索引擎的可用性仍受外部服务影响。
- 子进程关闭 execa 默认环境继承，避免安全环境被平台秘密补回；超时/取消清理 Unix 派生进程组。默认内置合同单次命令 15 秒；长时交互终端会话不在此次实现范围。

### 现有部署登记

在目标部署已配置的环境中执行；租户及用户必须真实存在并匹配，脚本不创建账户、不修改密码或网络规则：

```bash
APP_ENV=development pnpm exec tsx scripts/register-builtin-tools.ts <tenant-id> <owner-user-id>
```

生产使用 `APP_ENV=production`，准备 `pnpm build:runtime` 构建的镜像，运行既有 `tool-execution-worker` 和 `control-plane-outbox-worker`。独立 Worker 必须与 Web 使用一致的环境、数据库及签名配置。桌面执行还需配置 `SNOW_CONTROL_PLANE_PUBLIC_URL`，Web 进程启用既有 Bridge 服务并连接目标设备。生产 URL 必须为 HTTPS。

开发环境仅在明确允许本机命令时设置 `RUNTIME_DEFAULT=host`。联网通过 `WEB_FETCH_DOMAIN_ALLOWLIST` 配置具体域名；测试样例域可以用 `example.com`，不使用通配全放行。

## 实施约束

- 继续使用 `tool.call → ToolCall → PermissionDecision → ToolExecutionBinding → Worker → Observation`；内置工具与 webhook 共用审计、幂等、错误传播和恢复链，不另造直通 Bash 通道。
- 工具实现由已发布合同选择；模型仅提交工具参数，不能指定 executor 模块、设备或平台密钥。
- 执行目标由服务端可信工作区、环境与设备绑定冻结。重试使用原目标；目标不可用时明确失败或等待，不换机器。
- 主对话无需 Agent。基础解释与写作可直接回答；实时或外部事实使用可用工具。当前时间可作为通用系统上下文，但不是命令或联网能力的替代品。
- 公开进度、动作生命周期、工具结果和最终回答分开；只显示公开说明，不请求或展示模型内部推理。
- 同一操作准备、开始、完成原位更新；完成记录默认折叠，可查看参数和结果。实时、恢复、历史加载共享投影。

## 验收行为

1. 无 Agent 时问候、介绍和日期问题能够完成，执行环境不可用不阻断基础聊天。
2. 命令结果包括实际设备、工作目录、退出码与输出。Web/桌面切换不改变任务执行位置。
3. 网络检索返回真实来源；空允许列表、拒绝域名、SSRF、超时和结果超限有确定失败结果。
4. Desktop 断线、租约失效、跨用户或租户请求不能落到其他设备或服务器。
5. UI 查看操作详情、复制、终态折叠、刷新恢复、窄屏与连续缩放通过真实应用验证。

## 验证结果与边界

- 真实浏览器、测试管理员、未选择 Agent：基础日期回答完成；正式命令确认 → Resume → Worker → Observation → 模型正文完成。`date` 与 `pwd` 返回实际系统时间、任务工作目录及退出码 0，确认后约 9 秒收口。
- 真实网页读取：访问 `https://example.com`，约 12 秒返回 Example Domain 标题、用途与来源链接。不是静态样例或模型记忆回答。
- 原始无限思考根因：公开 progress 被恢复为用户输入，导致每轮决策失效。现在进度排除出上下文；只有真实用户 guidance 参与恢复。
- 完整工具确认链还修复了三个原有遗漏：Invocation 启动未同步 Turn running；工具确认缺少可见 Item/Event；确认后缺少 post-authority Resume 标记。均先复现失败，再修复。
- 真实 MySQL 8 验证权限、幂等、取消、Worker 与恢复；真实 macOS SQLite 工作区、签名 WebSocket 和原生命令验证设备固定及单次执行。原生链测试通过网关函数发起，尚未将 Electron 界面登录、跨进程 HTTP Worker 与原生执行串成一个端到端自动化用例。
- Web 与 Desktop 构建、全库类型检查、lint 通过；依赖检查在抽出共用 Provider 合同与响应读取后消除了新增循环依赖。启动/重试/恢复相关 106 项回归通过，确认与解析 46 项回归通过；登录和无 Agent 聊天 E2E 3 项通过。
- 执行界面复用 Lucide、Markdown/CodeBlock 和 UserActionItem；当前状态原位更新，完成记录折叠，回答正文不重复成为工具记录。真实页面覆盖展开、复制、刷新恢复及 360～1440px 的连续缩放，无页面横向溢出。
- 容器镜像验证受 Docker Hub token 服务连接超时阻断，不能将宿主机或桌面成功当成容器隔离验证。代码保持容器不可用时明确失败。
- 桌面沙箱允许网络访问；它不等同于 Web 工具的域名过滤。UI 暂停控制的是 Harness 推进；已发出的独立 Tool Worker 命令尚未统一接入立即取消协议，命令仍有合同超时，桌面断线/撤销已有原生终止处理。

这些是本次已运行行为及明确限制，不代表达到 Codex 所有工具、长时终端或跨平台隔离能力。
