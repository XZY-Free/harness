## 1. 背景与原则

- 拆分后三仓（nexharness / auth-center / nexharness-client）的 `main` 为开源通用版；企业能力通过**私有分支**叠加。
- 原则：**不改 main 结构**——企业代码全部落各仓 `enterprise/private-hr-integration` 分支；main 上保留的组合根注释（「私有发行版在构建时替换本模块」）为替换接口。
- 本机启动即企业版：三个企业分支工作区已就绪（`~/.config/superpowers/worktrees/<repo>/enterprise-private-hr-integration/`），本地 env 已适配。
- 迁移源：旧仓企业分支存档 `enterprise/pre-split-archive`（worktree 在 `~/.config/superpowers/worktrees/snow_harness/enterprise-private-hr-integration`，保留备查）。
