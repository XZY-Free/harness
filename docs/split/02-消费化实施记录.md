## 第一轮：消费方基础层（identity-client + 核心薄壳 + 认证入口切换）

**提交**：`af48e17c`（分支已推 origin）。

### 新增 `lib/identity-client/`（消费方 SDK，唯一身份出入口）

| 模块 | 内容 |
|---|---|
| config | `NEX_AUTH_CENTER_URL` + 各缓存 TTL/超时（env 可调） |
| session | token 提取（cookie/Bearer）、introspect（进程缓存 30~60s，TTL 与行为可注入）、票据兑换、token↔用户注册表 |
| snapshot | 权限快照缓存（5~15min）+ `peekSnapshot`（只读不触发网络） |
| evaluate | 快照本地清单匹配（与 auth-center `evaluatePermission` 语义一致：平台边界 + agent 策略/协作 + 企业收紧）+ 覆盖投影 |
| authorize | 实时授权（单/批；不可达抛 `AuthCenterUnavailableError`） |
| directory | 用户目录读（批量 + 分钟级缓存；供后续轮次接线） |

### 核心薄壳改写（保留历史签名）

- `lib/identity/resolver.ts`：`resolvePrincipal` → introspect 映射；`resolveCurrentUserContext` 同源；
  `resolveWorkloadPrincipal` 仍为本地 workload token 验证（不依赖 auth-center）；`AuthenticationError`/`authErrorResponse` 原样保留。
- `lib/identity/authorization.ts`：
  - `checkActionScope`：快照命中（进程缓存未过期）→ 本地匹配；未命中 → 实时 authorize；不可达 → **fail-closed 拒绝**。
  - `requireActionScope`（执法点）：**恒实时**（变更/敏感操作 100% 实时）；Service/Workload 分支不变。
  - `resolveActionScopeCoverage`：快照投影；不可用 → 空覆盖（fail-closed，不误暴露入口）。
- `lib/studio/nav-visibility.ts`：改走快照（studio.access + grant 动作集合）。
- `lib/identity/agent-call-permission.ts`：执行链显式 `{ realtime: true }`（运行期撤销立即生效）。

### 认证入口（登录归 auth-center）

- `app/login/page.tsx`：302 壳 → `{auth-center}/login?returnTo=<本站绝对地址>`（绝对地址含 origin）。
- `middleware.ts`（新）：拦截任意页面的 `?ticket=` → `POST /api/session/resolve` 兑换 → 写 `nex_session`
  cookie（HttpOnly/Lax/Expires）→ 302 到干净 URL；失败回 `/login` 重新走登录。
- 删除（已迁移 auth-center）：`app/api/auth/*`（6 操作）、`app/setup-password`、`components/auth/*`（5 件）。
- `instrumentation.ts`：移除身份扩展装配块。env：`.env.development`/`.env.example` 增 `NEX_AUTH_CENTER_URL`。

### 语义要点（消费方模型）

- 会话 cookie `nex_session` 的值 = **auth-center 会话 token**（开发期同 host 天然共享；票据流写同值 cookie）。
- auth-center 不可达：读路径 500（诚实失败，非 401 伪装）；授权检查 deny（fail-closed）。
- 快照匹配不做角色模板推导（grant 已预展开）；企业决策含在快照（agent 目录级）。

### 验证

- `typecheck` ✓ / `lint` ✓ / `build` ✓（Next 16 构建输出出现 `Proxy (Middleware)`，middleware.ts 生效）。
- **双服务联调冒烟 9/9**（真实 Chromium，脚本 `tmp/consumer-smoke.mjs`）：
  未登录 `/chat` → 307 链至 auth-center 登录页（returnTo=本站绝对地址）→ 登录 → `?ticket=` 回跳 →
  middleware 兑换落地 → 干净 `/chat` 渲染 → `/api/user/current`（经 introspect）→ 二次访问会话复用 →
  `/studio` 实时 authorize 门禁（admin 通过）。
- 服务日志无异常。
