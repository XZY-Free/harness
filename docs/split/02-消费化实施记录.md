## 第一轮：消费方基础层（identity-client + 核心薄壳 + 认证入口切换）

**提交**：`af48e17c`（分支已推 origin）。

### 新增 `lib/identity-client/`（消费方 SDK，唯一身份出入口）

| 模块 | 内容 |
|---|---|
| config | `NEX_AUTH_CENTER_URL` + 各缓存 TTL/超时（env 可调） |
| session | token 提取（cookie/Bearer）、introspect（进程缓存 30~60s，TTL 与行为可注入）、票据兑换、token↔用户注册表 |
| snapshot | 权限快照缓存（5~15min）+ `peekSnapshot`（只读不触发网络） |
| evaluate | 快照本地清单匹配（与 auth-center `evaluatePermission` 语义一致：平台边界 + agent 策略/协作 + 企业收紧）+ 覆盖投影 |
| authorize | 实时授权（单/批；不可达抛 `AuthCenterUnavailableError`） |
| directory | 用户目录读（批量 + 分钟级缓存；供后续轮次接线） |

### 核心薄壳改写（保留历史签名）

- `lib/identity/resolver.ts`：`resolvePrincipal` → introspect 映射；`resolveCurrentUserContext` 同源；
  `resolveWorkloadPrincipal` 仍为本地 workload token 验证（不依赖 auth-center）；`AuthenticationError`/`authErrorResponse` 原样保留。
- `lib/identity/authorization.ts`：
  - `checkActionScope`：快照命中（进程缓存未过期）→ 本地匹配；未命中 → 实时 authorize；不可达 → **fail-closed 拒绝**。
  - `requireActionScope`（执法点）：**恒实时**（变更/敏感操作 100% 实时）；Service/Workload 分支不变。
  - `resolveActionScopeCoverage`：快照投影；不可用 → 空覆盖（fail-closed，不误暴露入口）。
- `lib/studio/nav-visibility.ts`：改走快照（studio.access + grant 动作集合）。
- `lib/identity/agent-call-permission.ts`：执行链显式 `{ realtime: true }`（运行期撤销立即生效）。

### 认证入口（登录归 auth-center）

- `app/login/page.tsx`：302 壳 → `{auth-center}/login?returnTo=<本站绝对地址>`（绝对地址含 origin）。
- `middleware.ts`（新）：拦截任意页面的 `?ticket=` → `POST /api/session/resolve` 兑换 → 写 `nex_session`
  cookie（HttpOnly/Lax/Expires）→ 302 到干净 URL；失败回 `/login` 重新走登录。
- 删除（已迁移 auth-center）：`app/api/auth/*`（6 操作）、`app/setup-password`、`components/auth/*`（5 件）。
- `instrumentation.ts`：移除身份扩展装配块。env：`.env.development`/`.env.example` 增 `NEX_AUTH_CENTER_URL`。

### 语义要点（消费方模型）

- 会话 cookie `nex_session` 的值 = **auth-center 会话 token**（开发期同 host 天然共享；票据流写同值 cookie）。
- auth-center 不可达：读路径 500（诚实失败，非 401 伪装）；授权检查 deny（fail-closed）。
- 快照匹配不做角色模板推导（grant 已预展开）；企业决策含在快照（agent 目录级）。

## 第三轮：agent 执行链消费化（2026-10-14 完成）

schema 过渡表再裁剪（5 张）；快照同步。

### 语义定界（与本地实现等价）

- **装配服务化**：`prepareEnterpriseUserContext`（薄壳）= 转调 auth-center
  `POST /api/enterprise/user-context`。开源部署下 auth-center 无受信资料源（`createIdentityExtension`
  只给 authenticationProvider）→ 409 UNAVAILABLE → 薄壳映射回
  `EnterpriseUserContextRequirementError("...unavailable", "当前部署没有受信企业资料来源")`——
  **消息与迁移前逐字一致**；执行链上层仍转 `AGENT_CONTEXT_REQUIREMENT_UNSATISFIED`。
- **本地保留（终稿复核）**：`finalizeEnterpriseUserContextCandidate` 为**纯函数**（时间戳比较 + 投影一致性），
  在 binding 创建事务内做最终复核——无 IO、无跨服务调用（事务内 HTTP 是反模式）。
- **service-subject 分支**：显式抛 unavailable（与既有行为一致——原实现该分支恒因无 source 抛错）。
- **fail-closed**：auth-center 不可达/无活跃凭证 → unavailable；`signal` 不穿透 HTTP（等待上限由服务端
  10s 本地上限与客户端 15s 超时约束，执行链前后各自检查取消）。

### auth-center 侧

- **新接口** `POST /api/enterprise/user-context`（consumer 路由组）：
  Bearer 会话（主体=目标用户；`(tenantId, userIdentityId)` 必须与 principal 一致，否则 403）；
  入参 `{tenantId, userIdentityId, profileRequirement, allowedFields, deadlineAt?}`；
  出参 `{candidate}`（Date→ISO；none→null）；错误：401 / 403 / 409（三码：DISABLED 403、
  NOT_FRESH 409、UNAVAILABLE 409 retryable）/ 400（schema 或字段目录非法）。
- 新错误码 3 个（`ENTERPRISE_USER_CONTEXT_{DISABLED,NOT_FRESH,UNAVAILABLE}`）。
- 资料源取 `getIdentityExtensions().profileSource`（企业版构建替换 deployment/identity-extension）。

### nexharness 侧

- **identity-client/enterprise.ts（新）**：wire 层（`fetchEnterpriseUserContext` +
  `EnterpriseContextRpcError`）；`requestAuthCenter` 增可选 `timeoutMs`；config 增
  `enterpriseContextTimeoutMs`（默认 15s，覆盖服务端 10s 刷新等待）。
- **薄壳重写** `lib/identity/prepare-enterprise-user-context.ts`：HTTP 装配 + 错误映射 + 本地终稿复核；
  导出面收窄为 `prepareEnterpriseUserContext` / `finalizeEnterpriseUserContextCandidate` / 2 类型。
- **resume-agent-call**：停用检查从 `getUserIdentityForTenant` 改为直读 userIdentity stub
  （只读 status 列；与 store 终稿复核口径一致）。
- **删除 6 件**：`accept-enterprise-profile-observation` / `enterprise-permission-groups` /
  `enterprise-user-profile-queries` / `enterprise-profile-source` / `user-identity-queries` / `tenant-queries`。
- **保留（修正 v4"全搬"口径）**：`enterprise-user-access-policy`（读本仓 AgentRevision + 纯解析/投影——
  数据源是本仓，auth-center 无法替代）+ `enterprise-user`（字段目录/类型——协议词表角色）。
  lib/identity 收敛至 **24 文件**（v4 B 表 19 件 + 上述修正件）。

### schema 过渡表再裁剪（12 → 7）
